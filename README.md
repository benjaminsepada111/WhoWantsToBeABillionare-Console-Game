# Who Wants to Be a Billionaire – Console Game

**Project Type:** Java Console Application  
**Year:** First-Year College(2022-2023)
**Compiler/Editor:** TextPad  
**Purpose:** Beginner programming project, practicing fundamental Java concepts  

---

## Description
This is a **console-based quiz game** called **"Who Wants to Be a Billionaire"** developed as a **first-year college project**. It allows the player to answer **multiple-choice questions** and earn virtual rewards based on correct answers.  

The project is built entirely in **Java**, using only **basic programming concepts**, as an introduction to coding and game logic. This project demonstrates fundamental skills like **conditional statements, loops, methods, and handling user input**.

---

## Features
- Interactive **multiple-choice quiz** in the console  
- Supports **lifelines** for assistance:  
  - **50/50** – removes two incorrect answers  
  - **Ask the Audience** – simulates audience help  
  - **Switch the Question** – replaces the current question  
  - **Double Chance** – allows two attempts on a question  
- Shows **score/rewards after each question**  
- Immediate feedback for correct or wrong answers  
- Runs **locally** in the console without any internet connection  

---

## How to Run
1. Open the project folder in **TextPad** (or any Java compiler/editor).  
2. Compile the `.java` file(s).  
3. Run the main class.  
4. Follow the instructions in the console to play the game.
